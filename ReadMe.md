# 🌦️ Bias Correction of Weather Forecast using LDAPS Dataset

## 📌 Overview

This project focuses on improving temperature forecasts generated by the **LDAPS (Local Data Assimilation and Prediction System)** using data-driven techniques.

Instead of predicting temperature from scratch, the goal is:

> 🎯 **Bias Correction** — reducing the error in LDAPS predictions using statistical and machine learning models.

---

## 🎯 Problem Statement

LDAPS provides next-day temperature forecasts, but:

- It shows **systematic bias**
- Performance degrades under **extreme weather conditions**

### Objective:
> Improve LDAPS predictions using **hybrid modeling approaches**

---

## 📊 Dataset Description

- 📍 Location: Seoul, South Korea  
- 📅 Time: Summer (June–August), 2013–2017  
- 📦 Observations: ~7750  
- 🔢 Features: 25  

### 🔹 Key Variables

| Type | Variables |
|------|----------|
| Temperature | Present_Tmax, Present_Tmin |
| LDAPS Forecast | Humidity, Wind Speed, Cloud Cover, Precipitation |
| Geography | Latitude, Longitude, Elevation (DEM), Slope |
| Target | Next_Tmax, Next_Tmin |

---

# 🔍 Exploratory Data Analysis (EDA)

## 📈 Key Observations

### 🌡️ Temperature
- Present temperatures follow **approximately normal distribution**
- Strong correlation:
  - Present_Tmax → Next_Tmax
  - Present_Tmin → Next_Tmin

---

### 💧 Humidity
- RHmin ~ normal distribution  
- RHmax is **left-skewed (high humidity dominant)**
- Negative correlation with temperature  

---

### 🌧️ Precipitation
- Highly **skewed with many zero values**
- Rainfall events are **rare**

---

### 🔗 Correlation Insights

- Strong predictors:
  - LDAPS_Tmax_lapse (~0.83 correlation)
  - Present_Tmax (~0.60)

- Multicollinearity:
  - Cloud cover & precipitation variables

---

# ⚠️ LDAPS Error Analysis

## 🔹 Error Definition

Error = Actual - LDAPS Prediction

---

## 📊 Findings

- Error distribution ≈ **normal**
- Slight **positive bias** → LDAPS underestimates temperature
- Tmax predictions:
  - Higher variance  
  - Less stable  

---

## 📉 Error Behavior

### 🌡️ Temperature
- Error increases with higher temperature  
- Model underestimates extreme heat  
- Presence of **heteroscedasticity**

---

### 💧 Humidity
- Higher humidity → higher error  
- Indicates strong influence on prediction accuracy  

---

## 🧪 Feature Insights

- Interaction feature:
  Temperature × Humidity  
  → Stronger predictor of error

- Temperature range → weak influence

---

## 📊 Segmentation

| Temperature Level | Error |
|------------------|------|
| Low | Low |
| Medium | Moderate |
| High | High |

👉 LDAPS struggles under **extreme conditions**

---

# 🧠 Key EDA Insight

> Weather prediction is a **multivariate physical system**, not just a time-series problem.

---

# ⚙️ Modeling Approach

## 🔹 1. Baseline (LDAPS)

- RMSE ≈ **1.65**
- Strong but biased model

---

## 🔹 2. Linear Regression

- RMSE ≈ **1.49**
- Captures mostly **linear relationships**

---

## 🔹 3. Random Forest

- RMSE ≈ **0.98**
- Captures nonlinear patterns  
- Shows **overfitting (train-test gap)**

---

## 🔹 4. ARIMA

- RMSE ≈ **3.6**
- Performs poorly  
- Ignores external variables  

---

## 🔹 5. SARIMAX (Hybrid Model)

Model:
Next_Tmax = f(past values + LDAPS_Tmax_lapse)

- RMSE ≈ **1.40**
- Best **interpretable model**

---

# 🔬 Modeling Pipeline

- Station-wise modeling (125 time series)
- Time-based train-test split (80-20)
- No data leakage
- Evaluation on unseen data only

---

# 📊 Final Results

| Model | RMSE |
|------|------|
| ARIMA | 3.62 ❌ |
| LDAPS | 1.65 |
| Linear Regression | 1.49 |
| SARIMAX | 1.40 ✅ |
| Random Forest | **0.98 🔥** |

---

# 🎯 Key Insights

- LDAPS is already a strong baseline  
- Linear models perform well → system is **locally linear**  
- Random Forest captures nonlinearities but overfits  
- ARIMA fails → weather is not purely time-series  
- SARIMAX balances:
  - Physical modeling  
  - Time dependency  

---

# 🔥 Final Conclusion

> Hybrid models combining physical forecasts (LDAPS) with statistical correction (SARIMAX) significantly improve prediction accuracy.

---

# 🚀 Key Takeaway

> Weather forecasting requires combining **domain knowledge + data-driven modeling**
